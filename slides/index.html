AI를 막는 것이 아니라,

생산성은 활용하되, 결과는 검증 가능해야 한다.

AI slop in security reports

AI SLOP 과 AI 판타지로 고통 받는 현업자들

cURL 프로젝트는 AI가 만든 저품질 보안 신고가 유지보수자를 소진시키는 과정을 공개했고, 결국 버그바운티 종료를 발표했다.

The I in LLM stands for intelligence 그럴듯하지만 틀린 AI 취약점 보고서가 유지보수자를 속이고 검증 시간을 빼앗는다는 초기 경고 Death by a thousand slops AI slop 취약점 보고가 curl 팀을 지치게 만든다는 문제 제기 The end of the curl bug-bounty 16시간 동안 7건, 1월에 20건 이상 제보됐지만 실제 취약점은 0건. 덤프까지 첨부된 보고서를 모두 검수해야 했다.
Not only curl

curl만의 특수한 문제가 아니다

Log4j와 Node.js도 같은 피해를 공개했고, 생태계·플랫폼 차원의 대응을 논의할 정도로 확산된 문제다.

AI가 결과를 만드는 속도보다, 사람이 검증해야 하는 비용이 더 큰 병목이 된다.

Chapter 1 takeaway

AI를 배척하자는 이야기가 아니다

AI는 정말 중요하고 강력한 도구다. 문제는 도구의 가능성을 넘어, 모든 것을 해결해 줄 거라는 AI 판타지에 빠지는 순간이다.

AI는 활용해야 한다 생성 속도와 보조 능력은 이미 현업의 중요한 생산성 도구다.
부채는 누군가 치운다 AI가 만든 보안 부채와 검증 부채는 결국 사람이 확인한다.
전문성이 차이를 만든다 AI를 잘 쓰면서 자기 영역의 지식을 갖춘 사람이 문제를 해결한다.

AI를 잘 쓴다는 것은 많이 생성하는 것이 아니라
검증 가능한 결과를 만들게 하는 것이다.

AGENTS.md design

AGENTS.md에 넣을 것과 빼야 할 것

  • 이번 작업에만 필요한 일회성 지시

Capability and guardrails

Tool과 Permission은 함께 설계한다

T
Tool 파일 읽기·수정, Shell 실행, 검색처럼 실제 환경에 영향을 주는 작업 수단
P
Permission 허용, 사용자 확인, 차단으로 Agent의 행동 범위를 제한하는 정책
H
Hook 실행 전후에 검사, Build/Test, 변경 범위 검증을 자동으로 연결

Agent에게 능력을 주는 것만큼, 언제 어떤 능력을 사용할 수 있는지 제한하는 것도 중요하다.

Skill vs Command

지식과 진입점을 분리한다

Skill

  • 특정 작업에 필요한 재사용 지침
  • 프로젝트 절차와 업무 지식 문서화
  • 필요한 시점에 Agent가 읽어 활용

Command

  • 반복 작업의 정해진 진입점
  • 특정 Agent 또는 Skill과 연결
  • 사용자 요청 형식을 표준화
Reusable workflow

Skill은 반복 가능한 업무 방식을 제공한다

Q
grill-me 모호한 요구사항의 누락 조건, 범위, 예외를 먼저 질문한다.
P
make-phase 명확해진 요구사항을 Goal, Scope, Done Criteria가 있는 Phase로 바꾼다.
R
run-phase 승인된 Phase를 실행 규칙, 검증, 상태 기록 흐름에 맞춰 수행한다. 
모호한 요청 → grill-me → 명확한 요구사항 → make-phase → 승인된 Phase → run-phase / Runner → Verify

3. PhaseGoal, Inputs, Out of Scope, Done Criteria, Verification을 명시한다.
4. Runner실행 순서, 승인, 상태 기록, Hook, 재시도와 재개를 관리한다.
5. Loop실행 결과 평가 → 실패 원인 분석 → Phase 보완 → 재실행으로 확장한다.
Operating principles

운영 원칙

검증 없는 사용 금지AI 결과를 그대로 반영하지 않는다.
규칙은 저장소에개인 프롬프트가 아니라 프로젝트 자산으로 남긴다.
범위와 완료 기준작업 범위와 Done Criteria를 명시한다.
상태와 근거 기록실패 상태, 테스트 결과, 검증 근거를 남긴다.

AI 산출량보다 검증된 결과의 품질을 평가한다.

Harness to Loop
